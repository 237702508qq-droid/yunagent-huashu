03 / PROBLEM

模糊指令的三个失败瞬间

同样的指令，Agent 给不出你想要的答案

SCENE 01

找不到所指

「把昨天张三发我的方案改一下」

AGENT 的反应

「请问是哪个文件？张三是谁？」——连续反问，用户只得自己去找

SCENE 02

不懂岗位

「帮我写个周报」

AGENT 的反应

生成通用模板——不知道你是销售还是研发，用户仍要大改

SCENE 03

答非所问

「按我 usual 的格式整理」

AGENT 的反应

无法理解「usual」指什么——你的格式习惯从未被记住

每一次失败都在消耗用户耐心——这是小白用户放弃 Agent 的首要原因
