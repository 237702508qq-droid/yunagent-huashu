问题 · 现象PROBLEMS

两个典型问题

问题 01PROMPT-HEAVY

用户提供很多提示词，输出效果仍然较差

用户提示词 · 已描述得很详细

「我是云桌面的产品经理，写一个 VDI 相关的需求文档，主要针对 xx 客户提出的 xxx 移动端的问题」

Agent 回复的四类缺陷
A内容比较空
B专业名词的理解存在偏差
C文档的格式不是我想要的
D内容超出我的工作边界

公司通常构建企业上下文让 Agent 理解企业业务；但 Agent 不理解个人的偏好、工作边界、常用词，依然无法高质量输出。

问题 02FUZZY-INSTRUCTION

很难通过模糊指令达成目标

用户提示词 · 模糊指令

「昨天张三发了我一个 PPT，名字好像是“什么什么 云桌面 xx 方案”，请使用这个数据帮我生成一份需求文档，就按照我昨天输出的那个需求文档格式来就行」

Agent 的反问
Q1昨天的需求文档是什么格式？
Q2昨天张三是在哪里发的这个 PPT？

办公桌面上发生的事情 Agent 并不知道——它只知道对话框里的事情。Agent 和人的记忆不一致，面对模糊指令就不知怎么办。
