02 / PROBLEM

为什么你的 Agent 总是「答非所问」

两个高频痛点：提示词再多也经常走偏 · 模糊指令难以达成目标

场景

「昨天我和张三沟通的内容，帮我生成一个客户交流的材料。」

Agent 无法定位「昨天」「张三」——只能反问或沉默

01

无记忆

NO MEMORY

Agent 只能记住对话框里的内容；你在桌面里做过什么、看过什么，它一无所知。

02

无语境

NO CONTEXT

不了解你是谁、岗位与工作边界是什么、写作偏好是什么——输出千篇一律，只能「抽卡」式地猜你要什么。

03

无主动感知

NO AWARENESS

只能被动等待指令，无法从你的日常工作中学习，更谈不上主动补全语境。

这不是模型能力问题，是「上下文断层」——Agent 与你的真实工作环境之间缺一座桥

03 / PROBLEM

模糊指令的三个失败瞬间

同样的指令，Agent 给不出你想要的答案

SCENE 01

找不到所指

「把昨天张三发我的方案改一下」

AGENT 的反应

「请问是哪个文件？张三是谁？」——连续反问，用户只得自己去找

SCENE 02

不懂岗位

「帮我写个周报」

AGENT 的反应

生成通用模板——不知道你是销售还是研发，用户仍要大改

SCENE 03

答非所问

「按我 usual 的格式整理」

AGENT 的反应

无法理解「usual」指什么——你的格式习惯从未被记住

每一次失败都在消耗用户耐心——这是小白用户放弃 Agent 的首要原因
